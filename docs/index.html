Ask a question on GitHub
Is MK PDF free?

Yes. Every version on the release page is a free download for Mac, Windows, Android and iPhone, with no account and no ads.

Are my documents uploaded anywhere?

No. Editing, signing, text recognition, compression and conversion all happen on your device. MK PDF has no server and collects no data. The only thing it asks the internet is whether a newer version exists.

Does it really change the text, or draw over it?

It changes the text. The original letters are removed from the page and the new words are written with the same font, so the result is still searchable, selectable text, not a white box with a label on top.

Can I edit a scanned document?

Yes. When you edit a page that is only a picture, MK PDF recognizes the text offline first. Your edit paints over the old line in the paper colour and writes the new words in the ink colour.

Is every feature on every platform?

Almost. The AI assistant needs Apple Intelligence, so it is on the Mac only. Translation uses Apple's on device translator, so it is on the Mac and on iPhone with iOS 18 or later. Everything else is the same everywhere.

Why does my computer warn me the first time?

The release builds are not signed with a paid certificate yet. On a Mac, right click the app and choose Open. On Windows, choose More info and then Run anyway. You only do this once.

How do I install it on iPhone?

Apple only runs signed apps, so sign the IPA with a sideloading tool such as AltStore or Sideloadly and your Apple ID. With a free Apple ID it has to be signed again every 7 days, which the tool can do for you. Saved files appear in Files under On My iPhone, MK PDF.

How do updates work?

MK PDF checks for a new release when it opens, every hour, and when you switch back to it. Choose Download and Install and it replaces itself and restarts. Your settings and signatures stay.

What can't it do yet?

Certificate based digital signatures, PDF/A conversion and turning Excel or PowerPoint files into PDFs are not included. Rotated or vertical text, and text inside some embedded objects, can't be edited in place yet; use Cover and retype for those.
